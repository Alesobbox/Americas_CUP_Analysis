1# AC40 replay dashboard23The dashboard has five views: Replay, Analysis, Compare, Reports, and Forecast. It exposes 28 source sessions: nine Cagliari races and nineteen Naples races, containing 224 replayed boat-races.45## Runtime and data flow67- `src/main.tsx` mounts `App.tsx`, which owns race, playhead, primary boat, comparison boat, and visibility state.8- `src/components/dashboard/` contains the dashboard controls. `canvas/` renders boats, marks, boundaries, and trails. `panels/ComparisonPanel.tsx` compares boats at the shared playhead. `modals/` provides race selection and historical analysis.9- `src/engine/` loads data, interpolates replay frames, and calculates instantaneous replay geometry.10- `pipeline/run_pipeline.py` streams `Data/*.jsonl`, reconstructs events, and exports replay and historical artifacts.11- `pipeline/historical_analysis.py` owns historical formulas, units, availability rules, coverage, and event feeds. The browser reads its metrics.12- `scripts/build_artifact_inventory.py` publishes replay, analysis, and index downloads in Reports.13- `pipeline/environment.py` acquires historical model estimates for the header's sea height and temperatures, with source hashes and hourly availability. These provide replay context separately from the recorded wind and forecasting inputs. See [environment data](docs/environment_data.md).14- `scripts/analysis_snapshot.py` provides a bounded archive overview without printing telemetry arrays.15- `pipeline/prediction/` builds causal raw-data features, audited completion, joint ranking references, correlated Monte Carlo candidates and the AC38 tournament adapter. Forecast consumes immutable, content-addressed static JSON; it never fits a model in TypeScript. See [forecast implementation and evidence gates](docs/forecasting_implementation.md).1617Source measurements, interpolation, reconstructed results, estimated continuous gaps, and unavailable channels remain distinguishable. Source session assets determine boat identity and course marks. Map mode uses OpenStreetMap with attribution; Grid mode makes no tile requests. Virtual contacts describe geometric overlaps rather than official rulings.1819Historical analysis uses schema `2.0` and method `historical-2`.
