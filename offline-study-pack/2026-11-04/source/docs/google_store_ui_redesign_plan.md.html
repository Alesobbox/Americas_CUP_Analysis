Design objective67Give the project the visual discipline of the exact [Google Store Italy homepage](https://store.google.com/it/?hl=it) supplied by the user: clear hierarchy, confident typography, generous space, excellent imagery, carefully composed surfaces, and consistent interactions. Make the sailing archive itself supply the identity: real course geometry, boats, team colors, tracks, and evidence.89The intended experience is a calm, polished race-analysis product. A sailor should immediately see the race, a coach should quickly compare boats, and an analyst should be able to inspect and copy the evidence. Art direction and rules against a generic appearance4546### Product identity4748Use the existing product name and approved brand assets in a simpler treatment. Let a real course silhouette, a precise boat drawing, a selected track, or a leg interval provide visual interest. Keep the interface predominantly neutral so team identity and quantitative marks remain clear.4950Define three recognizable details and use them consistently: race-aware course thumbnails; a small, precise team-color marker paired with a text code; and a clear playhead treatment repeated across the map, transport, events, and telemetry. These details should feel native to this project.5152### Composition rules53541. Give each workspace one dominant subject: course, race report, boat comparison, export collection, or forecast question.552. Reserve large rounded surfaces for substantial visual or interactive regions. Use rows, spacing, and type for secondary information.563. Keep controls compact in operational areas; use more generous spacing in the race browser and report introductions.574. Use one strong action per local context. In Replay it is Play; in the race browser it is Open race; in a download row it is Download.585. Keep descriptive text next to the evidence it explains. Shorten repetitive explanations without removing their meaning.596. Review populated, partial, unavailable, and failure states as part of the design.6061### Explicit rejection criteria6263Reject decorative gradient blobs, glass panels, glow effects, animated background particles, fake activity, invented statistics, synthetic sailing photography, and generic feature grids. Reject repeated tiny uppercase labels above every heading, large meaningless icons, indiscriminate pills, and identical card treatments across the whole product.6465Avoid promotional phrases such as “unlock insights” and “the future of racing.” Use direct labels: “Race analysis,” “Compare boats,” “Source coverage,” and “Download CSV.” Choose one interface language for this pass; the Italian reference does not require translating the English product.6667The craft review must examine typography, alignment, image crops, empty space, chart labeling, control states, and copy individually. A distinctive logo cannot compensate for a generic layout.6869## 4.
