2

4

7## Intended result
8

24### Two data issues the implementation must address
25
26Reports currently uses legacy replay summary values, whereas Analysis uses source-covered historical metrics. For retired Naples GBR B, Reports shows 936.9 m and 0.9 kt while the canonical racing metrics are unavailable. For match-final ITA B, Reports shows 19,069.3 m while Analysis has 12,769.8969 m with partial coverage over 847.085 seconds. Reports must consume the canonical analysis values and their definitions; preserving the replay JSON does not require showing its legacy summaries as equivalent metrics.
27
28Thirteen of the 173 profiles with six available dimensions do not cover all course legs. In the match final, missing leg-5 crossing evidence prevents a complete leg-6 interval; the radar compares common legs 1-4 of a six-leg course. The interface must make this scope visible. Missing crossings may be repaired only when source evidence supports a reconstruction correction.

99### Visual precision and interpretation
100
101Show readable numeric scores near activated axes and a focused dot/leg-comparison view where 99, 100 and 101 are unambiguous. Keep a clearly labelled full-range circular chart with baseline 100. 123## 7. Agent C: make Cup uncertainty intelligible and correct
124
125### What the current numbers mean
126
127Pre-change snapshot (2 November 2026): the active baseline uses 5,000 trials. Exactly 1,718 paths are unresolved and 3,282 are resolved. Conservative [0,1] allocation of each unresolved path gives every team's baseline interval a width of 34.36 percentage points. The nine transfer assumptions then widen the combined envelope. For ETNZ, baseline bounds are 17.04-51.40%, while the combined envelope is 13.84-67.08%.
128
129The grid is transfer loading {0,0.5,1} crossed with residual-uncertainty multiplier {0.5,1,2}. These are assumptions, not fitted cross-class correlations or posterior weights. The displayed Transfer scenarios range already includes unresolved-rule uncertainty. Its endpoints may arise from different scenarios. Marginal bound endpoints must not be normalized to sum to one.
130
131Documentation says final Cup scenarios use 100,000 draws, but the current build relies on the helper's 5,000 default. Make the budget explicit and correct the documentation. More draws address numerical simulation error; they cannot remove unresolved-rule or transfer uncertainty.
132
133### Correctness and lineage before display changes
134
135Preserve observed-versus-missing strength provenance. The public mapping currently emits a numerical zero for an unobserved Australian team, while the simulator detects missing history by absent keys. That bypasses part of the missing-team prior treatment. Test and correct this public mapping path, distinguishing an estimated zero from no estimate. Audit the source model used to build Cup strength: the artifact must identify the exact model reference and training cutoff rather than implicitly inheriting the last loop model.
136
137Do not replace unresolved paths with an arbitrary lottery, a midpoint or a point probability conditional only on resolved paths. A missing-rule branch stays unresolved until evidence or a conservative feasible-path treatment justifies more information.
138
139### Evidence export and interface
140
141Export baseline scenario ID; every scenario's parameters, actual trials, seed, model/input hashes and conditioning assumptions; resolved/unresolved counts/fractions; per-team bounds; separate Monte Carlo error; unresolved reasons and first unresolved stage; and the scenarios producing each envelope endpoint. Keep overlapping reason counts separate from mutually exclusive first-unresolved-stage counts.
142
143Show Baseline assumptions: rule bounds and All tested assumptions: outer envelope as separate concepts. Add an existing-style scenario selector and expandable sensitivity table. The selected scenario remains an interval whenever its rules remain unresolved. Explain that the present nine scenarios do not span every uncertainty: reliability is conditioned on completed/scored races, weather response is zero, and AC75 transfer calibration is not established.
144
145Profile which rule clauses create unresolved paths. Where authoritative sources and a feasible branch budget permit, propagate only permitted outcomes and feasible champions; otherwise retain conservative bounds. Do not require narrower bounds as a pass criterion. Further genuine reduction depends on clarified rules, verified outcomes, AC75 target data and transfer validation. These evidence-acquisition tasks form a later research release, not a promise of immediate precision.
146
147Acceptance: public missing-team handling is tested; exact model/cutoff/seed/trial lineage is exported; counts reconcile; bounds reconstruct from scenario records; extrema IDs are correct; baseline belongs to the grid; structural uncertainty and simulation error are distinct; unresolved point estimates stay null; all three original forecast targets remain separate; content-addressed publication is atomic.

159## 9. Efficiency and completion rules
160
161Use the existing 28-session exports and compact summaries first. The source archive is 6.87 GB; no UI/theme/download-filter change should trigger a raw rebuild. Reuse existing per-leg evidence for the first chart release. If only performance metadata changes, implement a targeted refresh path instead of rescanning raw wind. Recompute models only when inputs or model logic change, with a fixed seed and explicit numerical budget. Save bounded failure excerpts rather than full logs or telemetry arrays.
162
163Workers report changed files, checks run, unresolved assumptions and candidate artifacts. Review code-to-export-to-visible behavior, not completion claims. Publish once through the orchestrator and rerun only checks affected by subsequent changes. Completion means all six annotations satisfy their acceptance checks, the original data and navigation remain compatible, and remaining model uncertainty is honestly explained. It does not mean forcing narrow probability ranges or manufacturing missing measurements.
