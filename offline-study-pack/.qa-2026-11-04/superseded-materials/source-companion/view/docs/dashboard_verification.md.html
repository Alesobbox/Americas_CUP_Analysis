20## Behavior and provenance
21
22- Fleet, map, telemetry and Analysis selections update the shared primary boat. Changing A preserves B; selecting the same boat for both produces an explicit prompt.
23- The named-boat filter affects map vessels and chart traces while retaining the complete fleet table.
24- Playback, seeking, speed, restart at the end, timeline filters, map tools, settings, chart selectors, race picker, notes, exports and detail panels perform their stated actions.
25- Notes are saved separately for each race. Race changes reset the race-specific selection and visibility.
26- Timeline and events use the Python event feed. Future events and untimed retirements remain hidden at earlier playheads.
27- Historical metrics retain Python formulas, coverage, quality, windows and denominator definitions. Analysis and Reports explicitly show retrospective results.
28- Heel and pitch are unavailable because no measured attitude channel exists. Current, sea state, temperatures, remaining route distance and map scale explain their unavailability.
29- Wind uses replay knots. Sparklines use actual replay samples; racing time gaps are labelled estimates.
30- OpenStreetMap is the default, with its attribution. Grid works without tile requests; failed tiles produce an explicit Grid fallback.
