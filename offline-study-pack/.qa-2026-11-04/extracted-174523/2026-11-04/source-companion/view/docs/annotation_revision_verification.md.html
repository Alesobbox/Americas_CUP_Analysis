65## Reproduce
66
67Use the repository Python environment with the locked forecast dependencies. Start the application, then set `REGATTA_URL` to its origin for browser tests:
68
69```powershell
70$env:REGATTA_PYTHON = Join-Path $PWD '.venv/Scripts/python.exe'
71./run.ps1 verify
72$env:REGATTA_URL = 'http://127.0.0.1:5190'
73npm run test:browser
74npm run test:annotations
75npm run test:forecast
76```
77
78To refresh performance evidence and CSVs without scanning raw wind:
79
80```powershell
81./.venv/Scripts/python.exe scripts/refresh_team_analytics.py --performance-only
82```
