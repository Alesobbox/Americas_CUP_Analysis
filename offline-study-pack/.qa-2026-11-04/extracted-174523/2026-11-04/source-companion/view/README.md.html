1# America's Cup AC40 replay dashboard
2
3Replay and historical analysis for 28 sessions: nine Cagliari races and nineteen Naples races, containing 224 boat-race tracks.
4
5## Dashboard views
6
7- **Replay:** boat and moving-mark tracks, wind, playhead-aware Tactical insights, reconstructed events, standings, telemetry, and local race notes.
8- **Analysis:** a white workspace with exported metrics, coverage, team history, interactive circular performance comparisons and a replay-linked Team debrief. Choose a dimension and leg to inspect exact peer evidence. Python owns historical calculations.
9- **Compare:** two explicitly selected boats at the shared playhead.
10- **Reports:** canonical race metrics, summary/performance CSVs and concise race downloads, plus a collapsed searchable technical archive.
11- **Forecast:** experimental race forecasts and gated event/Cup evidence, with separate baseline rule bounds, transfer scenarios and numerical error.
12
13Map mode uses OpenStreetMap with attribution. Offline Grid mode uses a 250 m metric grid without tile requests. True metric scale and enhanced visibility are available in Settings. Unsupported channels explain their unavailability. Reconstructed results and virtual contacts are not official classifications or umpire decisions.
14
15The interface follows the approved Google Store-inspired [design system](docs/design-system.md): a shared light palette, locally hosted DM Sans, a course-first Replay layout, and a searchable race library with lightweight source-course previews. See [implementation and verification](docs/ui_redesign_verification.md). Ingestion refreshes previews automatically; refresh them independently with `.venv/Scripts/python.exe scripts/build_race_previews.py`, then rebuild the download inventory with `.venv/Scripts/python.exe scripts/build_artifact_inventory.py`.
16
17## Run locally
18
19From Windows Command Prompt:
20
21```cmd
22cd /d "C:/Workspace/Americas Cup/2D_regatta_replay"
23npm ci
24npm run dev
25```
26
27Stop the development server with Ctrl+C before reinstalling dependencies.
28
29Regenerate replay and historical artifacts with `npm run ingest`. Refresh the team analytics from existing historical evidence and streamed source wind with `npm run analytics` (replay telemetry is preserved). See [team analytics](docs/team_analytics.md) for formulas and limits. Run frontend tests, production build, Python tests, reconstruction checks, and artifact integrity checks with `npm run verify`. Set `REGATTA_PYTHON` to a Python executable if it is installed outside the default Windows location. With the development server running, `npm run test:browser` checks the dashboard using installed Chrome.
30
31`npm run test:redesign` checks the race library's bounded loading, dialog focus, fullscreen, font loading, and all five workspace layouts down to 320 px. Set `REGATTA_URL` when using a different preview address.
32
33## Data flow
34
35```text
36Data/*.jsonl
37 → pipeline/run_pipeline.py
38 → public/data/replays/*.json
39 → public/data/analysis/*.json + index.json
40 → public/data/manifests.json + artifacts.json
41 → Replay / Analysis / Compare / Reports
42```
43
44When adding a race, ingest its source and confirm the replay, analysis index, and artifact inventory agree. `python scripts/analysis_snapshot.py` prints a compact overview. Raw sources are streamed; telemetry arrays remain downloads.
